Universal Design Principles Implementation

BSc(Hons) Software Engineering

1. Equitable Use

Identical access for all users: WCAG AAA High Contrast mode, Dyslexia-friendly font scale, and Text-to-Speech audio reader with LKR currency support.

2. Flexibility in Use

Full keyboard navigation (shortcuts '?', 'C', '/'), live multi-criteria filtering, price range slider, and multiple mock payment choices.

3. Simple & Intuitive

Standard e-commerce layout modeled on Amazon, eBay, and Argos. Clear 4-step checkout flow with visible progress indicators.

4. Perceptible Information

Redundant coding: colors, icons, text labels, and ARIA live regions ensure information is perceptible regardless of ambient conditions.

5. Tolerance for Error

Real-time form validation, stock bounds enforcement, instant "Undo" on item removals, and 1-click Demo Auto-Fill.

6. Low Physical Effort

Sticky header navigation, 1-click add-to-basket, quick-view modals, and persistent state avoiding repetitive user inputs.

7. Size & Space for Approach

Generous touch targets (min 44px), comfortable spacing, responsive layout for phones, tablets, laptops, and ultra-wide screens.
